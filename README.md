# Benjamin Houshmand

I work where reinforcement learning meets control: how a learned value function
can give a short-horizon planner such as MPC long-term foresight, and when a
learned component can be trusted inside a model-based controller. MSc in
Systems, Control and Mechatronics from Chalmers, with a master's thesis at
Volvo Group on decision-making for autonomous trucks. Based in Gothenburg.

**Projects**

- [learned-terminal-cost-mpc](https://github.com/benhou23/learned-terminal-cost-mpc):
  MPC for an autonomous truck in SUMO highway traffic, with a DQN value function
  as terminal cost. Code for the paper *Learned Terminal Costs for Short-Horizon
  MPC of Autonomous Trucks in Interactive Highway Traffic*
  ([arXiv:2610.40257](https://arxiv.org/abs/2610.40257)), joint first author with
  Hooman Hamze; under review.
- [cmapss-rul-prediction](https://github.com/benhou23/cmapss-rul-prediction):
  remaining useful life of turbofan engines with a CNN + LSTM, evaluated on the
  four C-MAPSS test sets (course project with Hooman Hamze).
- [knee-exercise-classifier](https://github.com/benhou23/knee-exercise-classifier):
  recognising knee rehabilitation exercises from encoder and IMU data (design
  project with Linnea Persson and Leo Barberan).

**Tools:** Python (PyTorch, Stable-Baselines3, NumPy, Numba, scikit-learn,
pandas), MATLAB and Simulink, SQL, SUMO/TraCI, Git, Linux, Docker
